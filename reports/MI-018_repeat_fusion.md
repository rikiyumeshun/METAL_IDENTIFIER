# MI-018 — Repetition, modality diversity, and open-set rejection
27 grades, 450 synthetic coupons per grade, 12 protocols and 3 bias scenarios = 437,400 condition-trials using the same 12,150 draws (not independent real specimens).
Input: simulation/metal_properties_v01.csv (nominal and provisional values, not audited certified data). Log-space within-state SD density .005, conductivity .07, thermal .07; material correlation conductivity/thermal .65. Readout random SD .01/.05/.10, reduced by sqrt(n); material scatter unchanged. Magnetic binary error .02, one test where included. Equal class priors and equal state priors within class. Bias scenarios add fixed log offsets (0,0,0), (.015,.08,-.08), (.03,.15,-.15); inference ignores bias deliberately. Assumed time 15 s density, 3 s conductivity, 12 s thermal, 2 s magnet per reading, illustrative only, excludes hardware/setup.
Closed-set top1 with ties fractionally scored; accept if nominal posterior >=.90 AND closest-state Mahalanobis d² <= 99th-percentile chi-square cutoff for measured continuous dimensions. This is a heuristic, not guaranteed calibration. Unknown stress: omit A2017, A7050, SUS316, C1100 from candidates and treat same simulated samples as unknowns. Unknown false accept is fraction of these held-out grades accepted as any remaining grade; cannot generalize to all unknowns.
## Results
Matched: conductivity 4 repeats 49.25%, 16 repeats 50.43%; density+conductivity 1 each 65.90%; full modalities 1 each 73.54%; full modalities 4 repeats continuous / 1 magnet 79.79%. Assumed times 12,48,18,32,122 s respectively. With fixed moderate bias full 1 repeat 65.99%, 4 repeats 65.65%; strong bias 54.14% vs 46.95%. Accepted accuracy for strong bias at 4 repeats only 9.60% (coverage 2.91%): high nominal posterior is unsafe under misspecification. Matched full 1 repeat accepted accuracy 98.09%, coverage 35.33%, heldout unknown false accept 50.94%; full 4 repeats unknown false accept 62.22%. Rejecting by high nominal posterior alone is inadequate; in-distribution confidence does not imply correct unknown detection. C1020 and C1100 identical in nominal features.
