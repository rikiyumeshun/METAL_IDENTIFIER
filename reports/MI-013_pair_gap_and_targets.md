# MI-013 — Pair-specific gap analysis
27 grades / 351 pairs; 199 pairs with identical assumed magnetic label analyzed. 20 have closest-state Mahalanobis distance D < 3.289707 (ideal equal-prior binary Bayes accuracy <95%). The other 152 pairs are excluded, not declared solved. Same log-space covariance as v0.1 bench: material sigma (.005,.07,.07); sensor sigma (.01,.05,.10); conductivity/thermal material correlation .65. Closest listed state is a conservative screening heuristic, not mixture accuracy. Additional independent feature effect required = sqrt(max(0,3.289707^2-D^2)). No measured effect sizes for new sensors yet. CSV generated by direct calculation; Python implementation supplied for reproduction, not executed in this run.
## Targeted composition facts (mass %)
- S45C C .42-.48; S50C C .47-.53: overlap .47-.48. Even exact carbon alone cannot always separate. Source: https://www.plutus.co.jp/en/productinfo/cold-rolled-special-steel-strip/
- SCM440 Cr .90-1.20, Mo .15-.30; S45C Cr <=.20 (supplier tables). Cr gap >=.70 percentage points in those ranges. Candidate element-selective assay, not validated on low alloy steels. https://www.sheng-maw.com.tw/aboutus.php?id=16 ; https://www.plutus.co.jp/en/productinfo/cold-rolled-special-steel-strip/
- A7050 Cr <=.04; A7075 Cr .18-.28. Gap .14 percentage points; Cu ranges touch at 2.0. Candidate chromium-selective assay; matrix-specific calibration mandatory. https://www.thyssenkrupp-materials-na.com/materials/aluminum/chemical-composition.html
- 304 vs 316: established Mo spot sorting (other Mo-bearing grades also positive), marks surface. https://www.assda.asn.au/publications/technical-faqs/testing-for-grade-confirmation
- C1020 vs C1100: equal conductivity and thermal conductivity per manufacturer; cuprous oxide detection by metallography is an established option (destructive specimen preparation). https://www.mitsubishi-copper.com/en/products/materials/cu_bar/ ; https://ecommerce.sist.si/catalog/standards/astm/d7ceaee2-9314-40e0-b0df7e7fbd7f8/astm-b577-19 (verify URL; standard ASTM B577-19).
- Steel thermovoltage sensitive to phase and carbon; room-temperature pair classification not demonstrated by high-temperature experiment. https://www.mdpi.com/2079-6412/14/8/980
