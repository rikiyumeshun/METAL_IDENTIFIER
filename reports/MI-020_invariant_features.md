# MI-020 — Invariant frequency response
8 nominal nonmagnetic grades from MI-016, 500 draws each; 4 nuisance scenarios × 3 noise levels × 4 algorithms = 192,000 condition-method trials reusing 4,000 synthetic samples. Within-grade conductivity log SD .05 (assumed). Single relaxation response x/(1+x²), x=f*pi*mu0*sigma*a², a=.003 m; eight frequencies 100–300000 Hz. Gain exp(-2*h/3), h uniform .2–1.7 mm. Additive offset SD .05 and log10-frequency slope SD .02 in corresponding cases. Normalized absolute additive white noise SD .005/.02/.05. Geometry stress uses +10% effective length. No actual coil Maxwell solution, circuit parasitics, magnetic effects, or empirical data.
Methods: raw nominal nearest template; nonnegative gain fit; remove mean and fit gain (affine); project out constant and log-frequency slope before fitting gain. Equivalent to nuisance regression. At offset+tilt, low/mid/high noise top1 raw 79.75/73.75/60.35%, projected 99.20/86.025/59.575%. With geometry bias, projected 58.7/60.3/52.075%: conductivity and effective length are structurally confounded. With gain only and mid noise, gain fit 88.15%, projected 86.025%. More nuisance parameters discard potentially discriminative information; select correction from independent calibration, not unknown specimen label. Avoid ratios with near-zero denominators. Residual diagnostics are needed to flag unknowns; identical spectral response cannot separate grades with same conductivity.
Reproduce: node simulation/MI-020_invariant_features.mjs. Exact study function executed in JS before committing; standalone file not independently executed. Public repository, generic model only. No hardware performance claims.
