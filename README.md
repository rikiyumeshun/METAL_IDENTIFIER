# METAL_IDENTIFIER

低価格な金属材質判定器の研究。公開物性値、物理モデル、実験を用いて識別可能性と限界を評価する。

## v0.1 基準実験
27材質、35材料状態、各条件81,000仮想試験片（3条件で243,000）。密度・導電率・熱伝導率・磁性を比較。卓上条件の正答率は密度＋導電率65.5%、全4物性73.3%。高精度条件では89.8%、92.4%。これは同一仮定モデル内の合成データであり実機性能ではない。

## 再現方法
Python 3 / numpy / pandas / scipy。 `python simulation/metal_id_sim.py` を実行すると物性表と結果CSVがスクリプトと同じフォルダに生成される。

## 評価方針
- 出典・温度・熱処理・単位を管理し、代表値と仮定値を区別する。v0.1の一部データは暫定値で出典との照合が未完了。
- 材料ばらつき、センサー誤差、形状・距離・表面状態を独立に評価する。
- 未知材質を強制分類しない。誤判定率、判定保留率、費用、測定時間を評価。
- 元素分析なしでは規格鋼種の完全識別が不可能な場合もある。
- 研究の次段階は実測データの取得と、独立した検証用試験片による評価。

現段階は公開物性に基づく基礎検討。機密情報や勤務先資料は登録しない。
